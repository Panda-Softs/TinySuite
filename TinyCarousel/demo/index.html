TinyCarousel

Dependency-free JavaScript carousel demo showing the main options and usage patterns.

1. Default 3D carousel with indicators

Drag, click a side item, use indicators, keyboard arrows, or API buttons.

const carousel = new TinyCarousel(document.querySelector('#default-carousel'), {
  indicators: true,
  duration: 200,
  dist: -100,
  shift: 0,
  padding: 0,
  numVisible: 5,
  fullWidth: false,
  noWrap: false,
  onCycleTo(item, dragged) {
    console.log(item, dragged);
  }
});

2. noWrap carousel

Stops at the first and last slide. This is useful when cyclic navigation would be misleading.

1 2 3 4 
new TinyCarousel(document.querySelector('#nowrap-carousel'), {
  indicators: true,
  noWrap: true,
  padding: 20,
  shift: 20,
  numVisible: 3
});

3. Full-width carousel

Uses full-width slides and automatic height from the active image/content.

A B C 
new TinyCarousel(document.querySelector('#fullwidth-carousel'), {
  fullWidth: true,
  indicators: true
});

4. Full-width with side preview, arrows and top dots

padding: '5rem' creates side padding so previous/next slides remain visible. The navigation arrows are generated by option.

1 2 3 4 
new TinyCarousel(document.querySelector('#preview-carousel'), {
  fullWidth: true,
  padding: '5rem',
  gap: '1rem',
  indicators: true,
  indicatorsPosition: 'top',
  arrows: true
});

5. Multiple slides: perPage and perMove

Shows three slides at once and moves one slide per navigation action.

1 2 3 4 5 6 
new TinyCarousel(document.querySelector('#multiple-carousel'), {
  fullWidth: true,
  perPage: 3,
  perMove: 1,
  gap: '1rem',
  arrows: true,
  indicators: true,
  indicatorsPosition: 'right',
  noWrap: true
});

6. Progress bar instead of dots

Use progressBar: true when you want a horizontal progression indicator instead of dots.

A B C D 
new TinyCarousel(document.querySelector('#progress-carousel'), {
  fullWidth: true,
  progressBar: true,
  arrows: true
});

7. Batch initialization with TinyCarousel.init()

Use this when the page contains multiple carousels using the same options.

X Y Z 
const instances = TinyCarousel.init(document.querySelectorAll('.batch-carousel'), {
  indicators: true,
  dist: -60,
  shift: 15,
  padding: 10
});
