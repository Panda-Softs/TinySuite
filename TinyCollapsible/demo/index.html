TinyCollapsible

A dependency-free collapsible component that keeps Materialize-style markup, removes jQuery/anime.js, and adds a dedicated menu controller for side menus with many collapsibles.

0jQuery
2Classes
CSSAnimation

Use TinyCollapsible for one accordion. Use TinyCollapsibleMenu to control a whole menu.

1. Basic accordion

One open item per instance.

  • Profile, billing and account settings.

  • Password, sessions and two-factor authentication.

  • Email, SMS and push notification preferences.

new TinyCollapsible('#basic', {
  accordion: true
});

2. Expandable mode

Several sections can stay open at the same time.

  • Define scope, constraints and expected output.

  • Implement the component and API.

  • Test keyboard, callbacks and nested menu behavior.

const expandable = new TinyCollapsible('#expandable', {
  accordion: false
});

expandable.openAll();
expandable.closeAll();

Menu API

The menu controller owns every nested collapsible instance. It is designed for side menus like your product menu.

const productMenu = new TinyCollapsibleMenu('#product_menu', {
  accordion: true
});

productMenu.expandAll();
productMenu.closeAll();
productMenu.expandUntil(document.querySelector('[data-product-id="77"]'));
productMenu.setActiveLink('[data-product-id="8"]');
productMenu.openByHeaderText('Kayak');
