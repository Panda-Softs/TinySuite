04 / SOFT DELETE

Undo before commit.

Removing a saved image only stages its filename for deletion. The server decides physical cleanup after a successful save.

Try it in the playgroundRemove an image, click Undo, then inspect removed[].
Show removal contract
JAVASCRIPT
await gallery.remove(imageId);
const state = gallery.getState();
// state.removed: ["old-name.webp"]
gallery.undo();
// Old file is never deleted by TinyGallery.

03 / INSTALL & INTEGRATENo build, no database dependency

Made for your forms.

TinyGallery only stages changes; persist them in your existing backend transaction.

1. Include the component assets
HTML
<link rel="stylesheet" href="TinyLightbox.css">
<link rel="stylesheet" href="TinyGallery.css">
<script src="TinyLightbox.js"></script>
<script src="TinyGallery.js"></script>
2. Create and clean up
JAVASCRIPT
const gallery = new TinyGallery('#product-gallery', {
  images: product.gallery?.split(';').filter(Boolean) || [],
  resolveUrl: filename => url_product(filename),
  onEdit: async img => externalEditor(img.src)
});
// Unmount when your modal closes:
gallery.destroy();
