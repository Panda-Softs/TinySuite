Standalone Vanilla JS

TinyChips

Chips input with input-source mode, JSON/CSV serialization, data transforms, autocomplete, AJAX data, validation and smart dropdown placement.

What to test

Submit-source input mode, val(), duplicate handling, pattern validation, object field mapping, load-once AJAX and onChange.

Input source mode: JSON default

TinyChips is instantiated directly on the real form input. The input value stays JSON.

Input source mode: CSV

Uses valueMode: 'csv' and separator: '|'.

AJAX loaded once

Uses data-autocomplete-source-url. The endpoint is fetched once without ?q=, then filtered locally.

Object data with field mapping

AJAX returns objects. valueField: 'value' tells TinyChips what to store/display.

Validation

Duplicate clears silently. ;..-- turns the input red until typing again.

Container mode

Classic div mode still works. No source input is synchronized.

val() API

Buttons call chips.val() and chips.val(value).
