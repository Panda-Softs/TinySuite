# TinySelectize 2.0.8

Fast, dependency-free enhancement for native `<select>` elements. TinySelectize supports single and multiple selection, local or asynchronous options, keyboard navigation, portal dropdowns, persistence, optgroups, custom rendering and plugins while keeping the original `<select>` as the source of truth.

## Quick start

```html
<link rel="stylesheet" href="TinySelectize.css">
<script src="TinySelectize.js"></script>

<select id="country" data-placeholder="Search…">
  <option value=""></option>
  <option value="ch">Switzerland</option>
  <option value="fr">France</option>
</select>

<script>
  const countrySelect = new TinySelectize('#country', {
    minChars: 0,
    searchField: ['label'],
    showSelectedInDropdown: false
  });
</script>
```

The original `<select>` remains synchronized, continues to participate in forms and dispatches its normal `change` event.

## Loading options

### Promise-based loader

```js
const citySelect = new TinySelectize('#cities', {
  minChars: 2,
  loadThrottle: 300,
  load: async ({ query, signal }) => {
    const response = await fetch(
      '/api/cities?q=' + encodeURIComponent(query),
      { signal }
    );

    const cities = await response.json();

    return {
      options: cities.map((city) => ({
        value: String(city.id),
        label: city.name,
        raw: city
      }))
    };
  }
});
```

### Selectize-compatible callback loader

```js
new TinySelectize('#cities', {
  minChars: 2,
  load(query, callback) {
    callback([{ value: '1', label: 'One' }]);
  }
});
```

### Built-in AJAX loader

```js
new TinySelectize('#categories', {
  valueField: 'id',
  labelField: 'title',
  ajax: {
    url: '/api/categories',
    queryParam: 'q',
    responsePath: 'data',
    mapOption: (category) => ({
      value: String(category.id),
      label: category.title,
      raw: category
    })
  }
});
```

In-flight requests are aborted when possible. A request identifier also prevents an older asynchronous result from overwriting a newer query.

## Loading state

Loading uses only the semantic wrapper state `.tsz--loading`. The rotating `loader03`-style ring is generated by `.tsz__control::before`, directly before the arrow, without an extra DOM element.

```css
.tsz {
  --tsz-loader-color: #7367f0;
  --tsz-loader-size: 0.9rem;
  --tsz-loader-border-width: 2px;
}
```

Set `showLoadingTextInDropdown: true` only when the textual `Loading…` status should also appear in the dropdown. The control receives `aria-busy="true"` during loading.

## Keyboard behavior

- `ArrowDown` / `ArrowUp`: move the active option.
- `Enter`: choose the active option.
- `Escape`: close the dropdown.
- `Backspace`: clear a single selection or remove the last multiple value when the query is empty.
- With `showTypeahead: false`, the control itself remains focusable and printable keys perform compact typeahead search.
- The active row is updated without rebuilding the entire dropdown DOM.
- When an asynchronous refresh completes, the active option is restored by value, even if its index changed.

## Public API

| Method/property | Purpose |
|---|---|
| `val()` | Read the current value. Returns `string|null` for single and `string[]` for multiple. |
| `val(value, silent)` | Set and synchronize the value asynchronously. |
| `value` | Property alias for the current value. |
| `addOption(option)` / `addOptions(options)` | Add local options. |
| `addItem(value)` / `addItems(values)` | Add selected values. |
| `clear()` / `clearItems()` | Clear the selection. |
| `clearOptions()` | Remove unselected options. |
| `refreshOptions(open)` | Recompute visible options. |
| `refresh(open)` | Reset remote state and refresh all options. |
| `updateOptions(options, open)` | Replace the configured option data. |
| `sync()` / `refreshItems()` | Synchronize from the native `<select>`. |
| `getSelectedOption()` | Return the selected raw object or option object. |
| `focus(open)` | Focus the correct input/control and optionally open. |
| `open()` / `close()` | Control dropdown visibility. |
| `enable()` / `disable()` | Change disabled state. |
| `clearStorage()` | Remove the persisted value configured by `storageKey`. |
| `destroy()` | Remove generated DOM/listeners and restore the original select and label. |
| `whenValueReady()` | Wait for the latest asynchronous value operation. |

## Main options

| Option | Default | Notes |
|---|---:|---|
| `placeholder` | `''` | Falls back to `placeholder` or `data-placeholder` on the select. |
| `minChars` | `0` | Minimum query length for remote loading. Local filtering still uses the current query. |
| `options` | `null` | Optional array used to populate the select. |
| `valueField` | `'value'` | Value field in option objects. |
| `labelField` | `'label'` | Label field in option objects. |
| `searchField` | `null` | Additional raw fields included in local search. Label and value remain searchable. |
| `sortField` | `null` | Raw fields used for stable sorting. |
| `sort` | `'match'` | `'match'` scores query matches; `'none'` preserves source/plugin order. |
| `loadThrottle` | `150` | Delay in milliseconds before invoking a loader. |
| `debounceMs` | `undefined` | Backward-compatible alias for `loadThrottle`. |
| `maxOptions` | `100` | Maximum number of rendered options. |
| `cache` | `true` | Cache remote results by query. |
| `preload` | `false` | Use `'init'` to preload built-in AJAX data during initialization. |
| `storageKey` | `null` | Persist and restore the latest selection through `localStorage`. |
| `openOnFocus` | `false` | Open after keyboard focus, subject to mode rules. |
| `observeSelectMutations` | `true` | Resynchronize after native option/attribute mutations. |
| `showClearButton` | `true` | Show the clear button when a value exists. |
| `showEmptyOption` | `false` | Render the empty native option in the dropdown. |
| `showSelectedInDropdown` | `true` | Keep selected values visible in the dropdown. |
| `showArrow` | `true` | Display the CSS arrow in single mode. |
| `showTypeahead` | `true` | Hide the visible single-mode input when `false`; the control remains keyboard searchable. |
| `showLoadingTextInDropdown` | `false` | Add a textual loading row in addition to the control spinner. |
| `allowEmptyOption` | `true` | Preserve explicit native empty options. |
| `defineWrapperValue` | `false` | Define a value proxy on the generated wrapper. |
| `typeaheadResetMs` | `600` | Reset delay for compact typeahead. |
| `load` | `null` | Promise-based or callback-based loader. |
| `render.option` | `null` | Custom option renderer returning a Node or HTML string. |
| `render.item` | `null` | Custom selected-item renderer returning a Node or HTML string. |
| `onChange` | `null` | Called with `(value, selectElement)`. |
| `onError` | `null` | Called when a non-abort load error occurs. |

### Dropdown options

| Option | Default |
|---|---:|
| `dropdownParent` | `null` |
| `dropdownDetachThreshold` | `140` |
| `dropdownAutoFlip` | `true` |
| `dropdownGapPx` | `6` |
| `dropdownZIndex` | `9999` |
| `dropdownCloseOnScrollParent` | `true` |
| `dropdownModalRootSelector` | `'.tiny-swal-container'` |

## Tree plugin

Load the plugin after the core:

```html
<script src="TinySelectize.js"></script>
<script src="TinySelectize.Tree.plugin.js"></script>
```

```js
new TinySelectize('#category', {
  options: categoryData,
  valueField: 'categoryId',
  labelField: 'title',
  sort: 'none',
  plugins: {
    tree: {
      parentField: 'parentCategoryId',
      valueField: 'categoryId',
      labelField: 'title',
      sort: 'id',
      sortDirection: 'asc',
      onlyLeavesSelectable: false,
      showChildCount: true,
      indentPx: 16
    }
  }
});
```

The plugin supports flat parent references and nested `children` arrays, protects against cycles, attaches depth/path metadata, can disable parent rows and remains styled in portal mode.

## Optgroups

Native `<optgroup>` elements work directly. Data-driven groups can use `optgroupField` and `optionGroupRegister`:

```js
new TinySelectize('#console', {
  options: consoleData,
  optgroupField: 'manufacturer',
  optionGroupRegister(groupKey) {
    return { value: groupKey, label: groupKey };
  }
});
```

## Persistence

```js
const selectize = new TinySelectize('#category', {
  storageKey: 'rental:lastCategory'
});

selectize.clearStorage();
```

A stored value is restored only when the native select does not already provide a preset value.

## 2.0.8 keyboard and mutation-observer fix

- `ArrowDown` and `ArrowUp` now navigate directly when the dropdown is already open; they never call `open()` again.
- `open()` is now a strict no-op for an already-open dropdown and can no longer close it during a transient loading state.
- Native-select mutation handling now distinguishes disabled-state, selection-only and option-source mutations.
- Selection-only mutations update the control without restarting AJAX loading.
- TinySelectize-owned writes to `<select>`, `<option>` and `<optgroup>` are suppressed and drained from the observer queue.
- `_syncFromSelect()` no longer refreshes options implicitly; refresh behavior is requested explicitly only where needed.
- Internal `change` events synchronize exactly once, preventing duplicate rendering.
- Added regression tests for delayed observer callbacks, open-state preservation and active-option preservation.
