Shared contextual dropdown

One dropdown menu reused for every table row. This is the right model for data-heavy UIs.

15 TinyDataTable-style row actions

The menu reads tr._data when available, falls back to tr.dataset, and exposes action helpers: show(), hide(), enable(), disable(), setHref().

Used code
const sharedClientActionsDropdown = new TinyDropdown('#client-actions-menu', {
  virtualTrigger: true,
  alignment: 'right',
  coverTrigger: false,
  constrainWidth: false,

  adjustMenuState({ data, setHref, show, hide, dropdown }) {
    setHref('view', `/fxbase/clients/${data.id}`);
    setHref('edit', `/fxbase/clients/${data.id}/edit`);

    data.canEdit ? show('edit') : hide('edit');
    data.canDelete ? show('delete') : hide('delete');

    dropdown.dataset.currentId = data.id;
  },

  onItemClick(item, event, context) {
    if (item.dataset.action === 'delete') {
      event.preventDefault();
      deleteClient(context.data.id);
    }
  }
});

clientsTable.addEventListener('click', (event) => {
  const trigger = event.target.closest('.js-client-actions');
  if (!trigger) return;

  event.preventDefault();
  sharedClientActionsDropdown.openFrom(trigger);
});
