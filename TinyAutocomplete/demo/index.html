Basic usage

Les exemples de base gardent une API proche de Materialize tout en retournant l’objet complet au callback.

1 Local simple

Recherche dans une liste locale d’objets simples. L’input prend la valeur du champ name.

Aucune sélection.
Code utilisé
TinyAutocomplete.init('#ex1', {
  data: fruits,
  valueField: 'name',
  onAutocomplete: item => setOut('out1', `Sélection: ${item.name}`)
});

2 Données type Materialize

Supporte un objet simple { Apple: null } pour faciliter la migration.

Aucune sélection.
Code utilisé
TinyAutocomplete.init('#ex2', {
  data: { Apple: null, Google: null, Microsoft: null },
  onAutocomplete: item => setOut('out2', `Sélection: ${item.value}`)
});

3 Static data + limit

Limite à 4 résultats sans AJAX. Utile quand la liste est petite et déjà disponible.

Maximum 4 résultats.
Code utilisé
TinyAutocomplete.init('#ex3', {
  data: locations,
  valueField: 'location',
  searchFields: ['postcode', 'location'],
  limit: 4
});

Rendering & linked fields

Le renderer reçoit l’objet complet et un helper highlight() qui injecte <span class="highlight">.

4 Renderer complet

Affiche NPA, localité et canton. Le champ sélectionné reste le postcode.

Aucune sélection.
Code utilisé
TinyAutocomplete.init('#ex4', {
  data: locations,
  valueField: 'postcode',
  searchFields: ['postcode', 'location'],
  renderer: locationRenderer,
  onAutocomplete: item => setOut('out4', `${item.postcode} · ${item.location}`)
});

5 Remplir un champ lié

Cas NPA classique : la sélection remplit automatiquement le champ localité.

Sélectionnez un NPA.
Code utilisé
TinyAutocomplete.init('#ex5', {
  data: locations,
  valueField: 'postcode',
  searchFields: ['postcode', 'location'],
  renderer: locationRenderer,
  onAutocomplete(item) {
    city.value = item.location || '';
  }
});

Sorting behavior

Sans sortFunction, le tri par défaut remonte les matches au début du texte, puis applique un fallback alphabétique.

6 Tri par défaut

Plan, Plaffeien et Plasselb passent avant Montplaisir.

Le meilleur match remonte naturellement.
Code utilisé
TinyAutocomplete.init('#ex6', {
  data: places,
  valueField: 'name'
});

7 Tri custom

Priorise les produits premium avant le tri naturel.

Aucune sélection.
Code utilisé
TinyAutocomplete.init('#ex7', {
  data: products,
  valueField: 'name',
  searchFields: ['name'],
  sortFunction(a, b) {
    return Number(b.priority || 0) - Number(a.priority || 0);
  }
});

8 Auto-select first

Affiche 3 résultats et pré-sélectionne le premier. Tapez puis appuyez sur Entrée.

Entrée sélectionne le premier résultat.
Code utilisé
TinyAutocomplete.init('#ex8', {
  data: locations,
  valueField: 'location',
  searchFields: ['location'],
  limit: 3,
  autoSelectFirst: true
});

AJAX and URL sources

Les appels réseau sont simulés dans la démo pour que le fichier fonctionne sans backend.

9 AJAX via option url

Utilise url dans les options. En production, remplacez par votre endpoint.

Aucune sélection.
Code utilisé
TinyAutocomplete.init('#ex9', {
  url: '/api/locations',
  valueField: 'postcode',
  searchFields: ['postcode', 'location'],
  renderer: locationRenderer
});

10 AJAX via data-url

L’URL peut venir directement de l’attribut HTML data-url.

Aucune sélection.
Code utilisé
<input id="ex10" data-url="/api/locations">

TinyAutocomplete.init('#ex10', {
  valueField: 'postcode',
  searchFields: ['postcode', 'location'],
  renderer: locationRenderer
});

11 AJAX via attribut url

Compatibilité avec un attribut url non standard quand le projet legacy l’utilise déjà.

Aucune sélection.
Code utilisé
<input id="ex11" url="/api/locations">

TinyAutocomplete.init('#ex11', {
  valueField: 'postcode',
  searchFields: ['postcode', 'location']
});

12 responsePath + requestData

Ajoute des paramètres de requête et lit une réponse imbriquée. Ici le backend simulé renvoie { payload: { items: [...] } }.

Aucune sélection.
requestData: canton=GE responsePath: payload.items
Code utilisé
TinyAutocomplete.init('#ex12', {
  url: '/api/nested-locations',
  responsePath: 'payload.items',
  requestData: () => ({ canton: 'GE' }),
  valueField: 'postcode',
  searchFields: ['postcode', 'location'],
  renderer: locationRenderer
});

Full initialization script

Tout le JavaScript de la démo est regroupé ici pour copie rapide.

Full demo JavaScript
const locationRenderer = (item, { highlight, escape }) => `
  <span class="option-row">
    <span class="option-icon">📍</span>
    <span>
      <span class="option-main">${highlight(item.postcode)}</span>
      <span class="option-sub">${highlight(item.location)} · ${escape(item.canton || '-')}</span>
    </span>
  </span>
`;

TinyAutocomplete.init('#ex4', { data: locations, valueField: 'postcode', renderer: locationRenderer });
TinyAutocomplete.init('#ex9', { url: '/api/locations', valueField: 'postcode' });
TinyAutocomplete.init('#ex10', { valueField: 'postcode' }); // URL from data-url
TinyAutocomplete.init('#ex11', { valueField: 'postcode' }); // URL from url attr

  url: '/api/nested-locations',
  responsePath: 'payload.items',

  valueField: 'postcode'
