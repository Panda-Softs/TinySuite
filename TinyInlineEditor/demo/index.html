03 / INTÉGRATION

Du HTML à l'édition.
En quelques lignes.

Une API volontairement simple, compatible avec l'ancien nom .inLine(). Aucun framework d'interface, aucun bundler.

✓ Configuration par éditeur✓ Changement de thème à chaud✓ Callbacks & autosave
app.js
// TinyInlineEditor en deux lignes
const $editor = $('#my-editor');

$editor.tinyInlineEditor({
  theme: 'dark',
  toolbar: ['bold', 'italic', 'link'],
  onChange: api => console.log(api.content)
});
