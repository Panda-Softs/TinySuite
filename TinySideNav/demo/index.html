TinySideNav Complete Demo

Pure JavaScript sidenav with overlay, left/right edges, triggers, API control, callbacks, close buttons, swipe support, body scroll lock, and CSS variable customization.

1. Basic left sidenav

Default left edge, draggable, overlay click close, and body scroll prevention.

Open with trigger 
const left = new TinySideNav('#left-nav', {
  edge: 'left',
  draggable: true,
  preventScrolling: true
});

2. Right sidenav

Same component, right edge. The trigger uses data-target.

Open with trigger 
const right = new TinySideNav('#right-nav', {
  edge: 'right',
  inDuration: 300,
  outDuration: 180
});

3. Draggable disabled

Useful when horizontal gestures conflict with another component.

Open no-drag nav 
const noDrag = new TinySideNav('#no-drag-nav', {
  draggable: false
});

4. Custom style + callbacks

Uses CSS variables and logs lifecycle callbacks.

Open custom nav
Callback log appears here.
const custom = new TinySideNav('#custom-nav', {
  edge: 'left',
  onOpenStart: logCallback,
  onOpenEnd: logCallback,
  onCloseStart: logCallback,
  onCloseEnd: logCallback
});

5. Batch initialization

Use this when multiple sidenavs should share the same options.

const instances = TinySideNav.init('.sidenav', {
  draggable: true,
  preventScrolling: true
});
