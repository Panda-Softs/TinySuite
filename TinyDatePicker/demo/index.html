Shared helpers

Reusable date utilities

All examples use the same compact helpers, keeping each configuration focused.

Show shared helpers Copy-ready 
const today = new Date();
const currentYear = today.getFullYear();

const addDays = (date, amount) => new Date(
  date.getFullYear(),
  date.getMonth(),
  date.getDate() + amount
);

const iso = (date) => [
  date.getFullYear(),
  String(date.getMonth() + 1).padStart(2, '0'),
  String(date.getDate()).padStart(2, '0')
].join('-');

const holidayKeys = [
  `${currentYear}-01-01`,
  `${currentYear}-05-01`,
  `${currentYear}-12-25`
];

Inline · disabled days

Weekends + custom business rules

const pickerDisabled = new TinyDatePicker('#inline-disabled-input', {
  mode: 'inline',
  locale: 'en',
  dateFormat: 'DD/MM/YYYY',
  assistDateInput: true,
  placeholderFromFormat: 'overwrite',

  },

Dark mode

The component automatically responds to a data-theme="dark" ancestor.

Show theme code Copy-ready 
const themeToggle = document.querySelector('#theme-toggle');

function applyTheme(theme) {
  const isDark = theme === 'dark';
  document.body.dataset.theme = isDark ? 'dark' : 'light';
  document.documentElement.style.colorScheme = isDark ? 'dark' : 'light';
  themeToggle.setAttribute('aria-checked', String(isDark));
}

// The demo deliberately starts in dark mode.
applyTheme('dark');
